# Roadmap

- [x] Версия 1: вход, качване на извлечения, категории, табло, асистент, изтриване на данни
- [x] Собствени категории (ръчно) + правила "текст съдържа X → категория" (ръчно или предложени от асистента с потвърждение)
- [x] Проверка end-to-end с тестов потребител
- [x] Асистентът е плаващо балонче над всички раздели
- [x] Начална страница с интерактивно дърво на финансите
- [x] Светла и тъмна тема с палитра 60/30/10
- [x] Визуална проверка на двете теми и мобилния изглед
- [x] „Теглене“ е самостоятелна автоматична категория за записи с „теглене“
- [x] Преглед на AI разпознаването ред по ред преди записване на извлечение
- [x] Асистентът скрива категории и подрежда списъка в „Транзакции“ без промяна на записите
- [x] Графиките се обновяват веднага при промени на транзакции, категории и банкови синхронизации
- [x] Нова собствена категория се показва в диаграмата дори с 0 € и без транзакции
- [x] Отделни диаграми за разходи и доходи по категории и за инвестиции по дестинация; категориите получават дял след транзакция
- [x] Диаграмата за доходи показва реалния източник на всеки приход, а не общата категория „Доход“
- [ ] Реално Revolut извлечение: проверка на брой, суми и категории (чака файл от потребителя)
- [ ] „Свържи банка“ чрез Enable Banking: екранът, връщането и синхронизирането са подготвени; реалната връзка чака регистрация и ключове
- [x] InfoPay: шифровано ERP свързване, четене на движения, дедупликация, часова синхронизация и ръководство за регистрация
- [ ] InfoPay: реална синхронизация (чака регистрация, активно съгласие и Unique ID/AccessToken от ERP интеграция)
- [ ] Android приложение за банкови известия (изисква отделен native проект извън това уеб приложение)

- [x] Точни справки, „Моите извлечения“ и защита от повторен импорт
- [ ] Enable Banking Sandbox демо: ключовете работят и банките се зареждат; чака публикуване на адреса за връщане
- [x] Enable Banking: поправка на формата на плащанията, дедупликация по банков идентификатор, „За проверка“
- [x] Премахване на декоративното дърво и плътно допрени сектори без бели контури
- [x] Кликаеми категории с диаграма по търговци, проценти, суми и връщане назад
- [x] „Къде харчите най-много“ непосредствено под „Разходи по категории“
- [x] Преименуване на приложението на Personal Accountant без промяна на домейна и Enable Banking callback
- [x] „Финансови цели“: месечни лимити, спестявания с ръчни заделяния и предложения от асистента с потвърждение
- [x] Кръговите диаграми следват качения визуален ориентир: плътен пръстен, заоблени сектори, процепи и леко отместване
