# Roadmap

- [x] Версия 1: вход, качване на извлечения, категории, табло, асистент, изтриване на данни
- [x] Собствени категории (ръчно) + правила "текст съдържа X → категория" (ръчно или предложени от асистента с потвърждение)
- [x] Проверка end-to-end с тестов потребител
- [x] Асистентът е плаващо балонче над всички раздели
- [x] Начална страница с интерактивно дърво на финансите
- [x] Светла и тъмна тема с палитра 60/30/10
- [x] Визуална проверка на двете теми и мобилния изглед
- [x] „Теглене“ е самостоятелна автоматична категория за записи с „теглене“
- [x] Преглед на AI разпознаването ред по ред преди записване на извлечение
- [x] Асистентът скрива категории и подрежда списъка в „Транзакции“ без промяна на записите
- [ ] Реално Revolut извлечение: проверка на брой, суми и категории (чака файл от потребителя)
- [ ] „Свържи банка“ чрез Enable Banking: екранът, връщането и синхронизирането са подготвени; реалната връзка чака регистрация и ключове
- [ ] Android приложение за банкови известия (изисква отделен native проект извън това уеб приложение)
